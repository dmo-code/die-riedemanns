# Die Riedemanns

Statische React-Webseite fuer einen landwirtschaftlichen Betrieb mit
Freilandeiern, Charolais-Rindfleisch und Mail-Anfragen fuer Fleischbestellungen.

## Entwicklung

```bash
npm install
npm run dev
```

## Statischer Build

```bash
npm run build
```

Der fertige Build landet in `dist/`.
